CURRENT CONTRACT · revision 0.9
Generated from the registry. IDs are permanent; only CURRENT records are normative.
Every repetition below is rendered from or cites one of these records. EXAMPLE sections cannot create a requirement.

R-SPC-001   legacy SPEC-001 · The registry is the only normative source. Generated artifacts filter current records; stable IDs survive reordering and superseded records remain addressable. section
R-COR-001   legacy CORE-001 · Keep one durable event record, one rendered window, and one model context. Eviction changes the window; compaction changes context; neither erases history. section
R-COR-002   legacy CORE-002 · A render event may change drawing but never keyboard ownership. Question arrival is an ownership request, not an ordinary render event. section
R-COR-003   legacy CORE-003 · Every actionable, status, and interaction distinction has two independent carriers and survives without colour. Dense data may shed colour-only detail only when a named readout preserves the meaning. section
R-STA-001   legacy STATE-001 · Lifecycle, outcome, resolution, ownership, focus, pointer, selection, choice, disclosure, availability, freshness, and validity are orthogonal axes; no generic active flag is stored. section
R-STA-002   legacy STATE-002 · A cell has one ground. Precedence is owner or armed, copy selection, focus, hover preview, semantic extent, then structural surface; displaced facts retain a mark, edge, or weight. section
R-STA-003   legacy STATE-003 · Hover may preview but never owns input. Focus adds a persistent non-colour carrier so hover cannot be mistaken for focus. section
R-OWN-001   legacy OWN-001 · Each ownership rung routes an action as handle, reject, pass, or global-intercept; exactly one declared owner or intercept acts. section
R-OWN-002   legacy OWN-002 · Events carry the owner epoch in which they began and are never replayed against a new owner. An attached child explicitly handles control-C and escape. section
R-OWN-003   legacy OWN-003 · Pointer press arms a stable id; release on the same id commits. Drag, owner change, identity loss, or release elsewhere cancels activation. section
R-QST-001   legacy QST-001 · Answer form and placement are independent. Choice-only defaults to replace; text defaults to float above the held prompt. A question declares blocking and owner explicitly. section
R-QST-002   legacy QST-002 · Inspection suspends a question and is not an answer. Every question resolves exactly once as answered, cancelled, or expired. section
R-QST-003   legacy QST-003 · Editor code is shared; buffers, undo stacks, and histories are isolated by owner. section
R-QST-004  Approval inspection is the third choice, labelled show full diff. It has no second key-only overflow route. section
R-MOT-001   legacy MOT-001 · Motion is full, reduced, or off and is independent of colour depth and glyph set. section
R-MOT-002   legacy MOT-002 · Work spinners use 80–200 ms frames; deliberate wait indicators may be slower. With motion off, a running call keeps a still mark and elapsed text carries liveness. section
R-MOT-003   legacy MOT-003 · The HTML preview conservatively maps the operating-system reduced-motion request to off; the product reduced setting may retain essential work or wait motion. section
R-MOT-004   legacy MOT-004 · Meaningful text remains contrast-safe in every frame; deep fades belong only to a decorative duplicate or mark, never the sole semantic carrier. section
R-MOT-005  A specimen animation may change only the glyph in a cell or that cell’s colour, opacity, or brightness. Transform, translate, scale, rotate, and layout motion are forbidden. Per-character stagger is retained. Glyph-swap frames resolve through a one-cell capability rung; ambiguous Unicode falls back to registered one-cell ASCII frames. section
R-PRG-001   legacy PROG-001 · A meter declares quantity, granularity, and liveness independently. section
R-TXT-001   legacy TEXT-001 · Storage offsets, grapheme indexes, token indexes, and display cells are distinct. Editing and public spans never split a grapheme; serialization keeps source offsets. section
R-GLY-001   legacy GLYPH-001 · Every semantic glyph declares a collision-free ASCII fallback, width by capability, and reservedCells equal to its widest representation. The renderer pads the selected representation to that reservation. section
R-CAP-001   legacy CAP-001 · Capabilities form a vector, not a ladder. Every action has a base-terminal route; enhanced protocols improve bindings but never create the only route. section
R-ACC-001   legacy A11Y-001 · Every component exposes semantics and announcement policy. Linear semantic events are append-only and non-animated; only the active input editor mutates in place. section
R-TRU-001   legacy TRUST-001 · Only the renderer emits terminal controls. User, model, tool, path, URL, and log content is escaped; a PTY interprets controls only inside its emulator boundary. section
