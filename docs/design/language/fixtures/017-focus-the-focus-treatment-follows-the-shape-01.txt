FOCUS = A PERSISTENT INDICATOR PLUS THE SHAPE'S FOCUS TREATMENT.
An unpainted run or box inverts; a frame takes its border or axes; a control washes.
A painted identity chip preserves its hue, bolds and takes a focus mark.

  a button        no tone      →  the accent
  a link          identifier   →  cyan, and the underline stays
  a paste chip    meta         →  purple
  a destructive   error        →  the error ground
  a chosen answer ok           →  the ok ground
  an agent chip   its own hue  →  already painted; focus bolds + marks it

colour is declared, not inherited: a button inside an orange region can
declare tone: "info" and invert to blue. The element owns its colour;
an unpainted run or box inverts it. A painted identity chip preserves its
hue; other shapes keep the same channel differently.

AND WHAT IT PAINTS DEPENDS ON THE SHAPE — an element is not always a row.

  A RUN      text with no frame      the RUN inverts
  A BOX      a button, a chip, a     an unpainted BOX inverts;
             choice, a full-width row painted identity bolds + mark
  A FRAME    a plot, an image, a     its BORDER — or its AXES when
             panel, a terminal       it has none. Inside untouched
  A CONTROL  a slider, a toggle, a   a WASH over ALL of it — label,
             checkbox, a radio       track and value

three presentations that compose, with independent mechanisms

  at rest    nothing, or the element's own resting ground
  focused    INVERT (unpainted run/box) · PRESERVE+BOLD+MARK (painted identity chip)
             the BORDER (frame) · a WASH (control)
  focused+insideHEAVY — the same light/heavy pair the plot border and the
             scrollbar already use
