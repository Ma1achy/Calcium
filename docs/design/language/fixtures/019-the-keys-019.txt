RESOLVED DEFAULT-TERMINAL KEYMAP · 39 bindings
The universal set gives one purpose to each key and does not depend on what has focus; the active owner resolves that purpose.
Actions are primary. Chords are the resolved profile. A named command route is the intended contract; only 1 of 39 bindings carry one today.

WHAT CHANGED DELIBERATELY, AND WHY
  ⌥⏎ for newline        → ⇧⏎      it is what people type and the protocol makes it detectable
  y to copy             → ⌃⇧C     a letter types a letter
  ⌘↓ as a pushed view   → ⌘↓ or scrollbottom is a location, not a mode
  n / p to move         → ↑↓      movement already belongs to arrows
  ⌃r for search         → ⌃⇧F     find follows the platform convention
  ⏎ to expand           → ⏎       kept because enter already means open

PLATFORM CONVENTIONS THAT STAY OWNED
  ⌥← and ⌥→ remain word-left and word-right in text fields; agent switching uses ⌃⇥ because agents are tabs.
  ⌃C remains interrupt. Copy uses ⌃⇧C, leaving the terminal convention intact.

CHORDS THAT ARE GENUINELY OURS
  ⌃⇥ and ⌃⇧⇥ switch agents because agents are tabs.
  ⌘1–9 jumps directly to an agent, matching browser tabs.
  ⌥↑ and ⌥↓ scroll a page; ⌘↑ and ⌘↓ move to the ends.
  ⌥p cycles the posture because that setting can surprise; ⌥v reveals per-token values; ⌥⌫ drops the last queued message.
