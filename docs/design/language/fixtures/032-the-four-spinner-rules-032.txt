four rules the sets obey, and every one is asserted rather than commented

1 · EVERY FRAME IS ONE CELL [R-MOT-005]
  by cells() and by the terminal. A two-cell frame shifts everything
  after it by one column on that tick — the whole line jitters, not
  the spinner.

  two ways a character fails: it is East Asian AMBIGUOUS (one cell
  or two, by setting), or it has an EMOJI PRESENTATION (one cell or
  two, by font). Registration measures every frame in the resolved
  terminal profile. If any primary frame is not exactly one cell, the
  WHOLE set takes its semantic ASCII fallback — never frame by frame.

2 · WORK FRAMES ARE 80–200 ms. Deliberate WAIT sets may be slower. [R-MOT-002]
  ✦  braille      80ms ·  10 frames
  ✦  pulse       120ms ·   6 frames
  ✦  fullramp    120ms ·  42 frames   ← same rate, more variety
  ✦  the walk    120ms ·  82 frames   ← the whole family

  Every WORK set is 80–200ms, from braille at 80 to arrow at 200.
  toggle at 400ms is a WAIT set: its slowness says nobody is busy.
  The semantic class, not one universal band, decides whether it reads alive.
  CYCLE LENGTH decides VARIETY, not liveness: 4-frame sets repeat every
  0.48–0.8s and a 42-frame one does not repeat for five seconds.

  an earlier pass said frames × interval must land in 800–1600ms. That made
  long alphabets look stuck. The band was wrong, not the catalogue:
  frame interval carries liveness; cycle length carries variety.

  the agent's walk is the one exception, and it is deliberate: it is
  not saying a step is in progress, it is saying the agent is alive.
  A ten-second cycle never looks like a loop, which is the point.

3 · A PING-PONG LOOPS 0 → N → 1, NEVER 0 → N → 0 [R-MOT-009]
  ▁▃▄▅▆▇▆▅▄▃     correct — the endpoints appear once per cycle
  ▁▃▄▅▆▇▆▅▄▃▁    wrong — ▁ held for two ticks, and it stutters

4 · THE ASCII PAIR IS MATCHED BY SHAPE OF MOTION, NOT BY LOOKS [R-MOT-010]
  ⠧⠳⠹⠼⠞⠏  →  | / - \\        both rotate
  ▏▎▍▌▋▊▉  →  . o O @      both grow
  ◐◓◑◒     →  | / - \\        both turn

  a set whose ascii pair does not MOVE the same way is a different
  animation at a lower rung, not the same one degraded.
