  underlined and in the identifier tone, so you know it is a link
  BEFORE you click — which is what makes a plain click safe.

  focused: parse.ts:41   — identifier hue, bold, link ground and focus edge
  is on the entry as usual

★ plain click opens. Not ⌘click.

  a terminal needs ⌘click because it CANNOT TELL a link from text —
  it is guessing at a URL with a regex. This app knows exactly where
  its links are, so it does not have that excuse.

  and ⌘click stays the TERMINAL's gesture, which is the other half
  of the reason: taking it would be fighting the emulator for a
  chord it will fire anyway.

  clicking the SENTENCE around a link focuses the entry, as any text
  does. Clicking the LINK opens it. That is how every browser has
  always worked and nobody has had to learn it.

the keyboard equal

  ⇥       links are in the focus ring, so tab reaches them
  ⏎       opens the focused one
  ⌃⇧C     copies the TARGET, not the label — the same
          copies-the-source rule everything else takes

what is NOT a link

  anything that RUNS something
  a link opens, reveals or navigates. It never executes — and the
  moment one does, every plain click in the transcript becomes a
  thing a reader has to think about.

  so re-running a call is ⏎ on the CALL, which is a focused element
  with a visible action — not an underlined word in a sentence.
