★ REUSING THE EDITOR IS NOT REUSING ITS STATE

  ONE line-editor implementation is right. SAME HISTORY is too broad.
  A normal prompt, a commit-message answer, a paste-chip editor and
  each subagent’s prompt need separate buffers and appropriately
  scoped histories and undo stacks — otherwise a question overwrites a
  half-written instruction, undo crosses between unrelated editors, or
  A SENSITIVE ANSWER APPEARS IN ORDINARY PROMPT HISTORY.
